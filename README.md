## Project Description
This project is a personal resume website created using HTML and CSS. 
It presents my personal information, educational background, technical skills, 
career goals, hobbies, and contact information in a simple and organized 
responsive web design.

## Features of the Website

- Personal Home section
- Profile picture
- About Me section
- Educational Background
- Skills section
- Career Goals section
- Hobbies and Interests section
- Contact Information
- Facebook and Instagram links
- Responsive website layout
- Navigation menu
- Hover effects and animations
- Organized and user-friendly design

## Technologies Used

- HTML5
- CSS3
- Boxicons
- Google Fonts
- GitHub
- GitHub Pages
